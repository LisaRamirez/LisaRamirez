## 👩‍💻 Qué hago

Construyo software que se usa todos los días y que tiene que seguir funcionando solo:

- 🏢 **Administración centralizada** — plataformas web que reúnen en un solo lugar la gestión de clientes, cobros, lecturas y reportes.
- 📡 **Telemetría y medición inteligente** — lectura de medidores, captura de datos desde equipos portátiles por puerto serie y paneles de seguimiento.
- ⛏️ **Servidores de Minecraft** — administración de una red completa (proxy, lobby y survival), compatible con Java y Bedrock, con plugins y automatización de avisos y reinicios.
- 🛒 **Tiendas y carritos de compra** — catálogos, carrito, pagos en línea y APIs conectadas a la tienda del servidor.
- 🤖 **Automatización** — programas que reemplazan tareas repetitivas y se recuperan solos de los fallos.

## 🎯 Hacia dónde voy

Quiero consolidarme como **desarrolladora de ingeniería de software**, especializada en:

- **Plataformas de administración centralizada** que reúnan en un solo sistema la gestión, la telemetría y los reportes.
- **Telemetría y monitoreo en tiempo real** de equipos de medición, con paneles claros para quien toma decisiones.
- **Migrar y modernizar sistemas** existentes a Python, con código mantenible, documentado y fácil de desplegar.
- **Integrar inteligencia artificial** en las herramientas de trabajo: análisis de consultas, detección de anomalías y apoyo en la gestión.

## ✨ Cómo trabajo

Me gusta dejar las cosas **documentadas, probadas y fáciles de instalar**: un README claro, instalación en un paso y un plan para cuando algo falla.
